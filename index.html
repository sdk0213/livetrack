자주 묻는 질문 (Q&A)

🏃‍♂️ 그룹 참가

Q. 그룹 참가 버튼이 활성화되지 않아요

A. 다음 조건을 모두 충족해야 합니다:

  • 참가코드 4자리 입력
  • 역할 선택 (주자 또는 응원)
  • 주자인 경우: 배번 입력 + 레디샷 사진 첨부 필수

Q. 참가코드는 어디서 얻나요?

A. 그룹장이 생성한 4자리 참가코드를 받아 입력하세요. 그룹장은 프로필 탭에서 코드를 확인하고 공유 버튼으로 전달할 수 있습니다.

Q. 배번을 잘못 입력했어요

A. 현재는 그룹 탈퇴 후 다시 참가하는 방법만 가능합니다:

  1. 프로필 탭 → "그룹 탈퇴" 버튼 클릭
  2. 참가 탭 → 올바른 배번으로 다시 참가

📸 레디샷 & 사진

Q. 레디샷을 변경하고 싶어요

A. 응원 탭 → 우리 크루 멤버 → 본인 이름 카드에서 "📸 레디샷 변경" 버튼을 누르세요. 본인 레디샷만 변경 가능합니다.

Q. 사진 첨부 후 취소하면 에러가 나요

A. 사진을 선택한 후 다시 파일 선택창에서 취소하면, 이전에 선택한 사진이 유지됩니다. "등록 완료"를 누르기 전에 사진을 확인하세요.

🎯 추적 시작

Q. 실시간 추적은 어떻게 되나요?

A. 대회 공식 데이터를 3분(180초)마다 자동으로 갱신합니다. 마커는 15초마다 예상 위치로 부드럽게 이동합니다. GPS를 사용하지 않으므로 주자의 위치 정보를 수집하지 않습니다.

👥 그룹 관리

Q. 그룹을 만들고 싶어요

A. 참가 탭 하단의 "새 그룹 만들기" 버튼을 클릭하세요. 대회를 선택하면 4자리 참가코드가 생성됩니다.

Q. 그룹을 탈퇴하고 싶어요

A. 프로필 탭 → "그룹 탈퇴" 버튼을 클릭하세요. 탈퇴 시 업로드한 레디샷도 함께 삭제됩니다.

Q. 여러 그룹에 참가할 수 있나요?

A. 아니요, 한 번에 하나의 그룹에만 참가할 수 있습니다. 다른 그룹에 참가하려면 먼저 현재 그룹을 탈퇴해야 합니다.

🗺️ 지도 & 마커

Q. 마커가 겹쳐서 클릭이 안 돼요

A. 비슷한 위치의 주자가 여러 명일 때, 자동으로 부채꼴 모양으로 라벨이 펼쳐집니다. 라벨을 클릭하면 해당 주자의 정보를 볼 수 있습니다.

Q. 정보창을 닫으려면?

A. 마커나 지도를 한 번 더 클릭하면 정보창이 닫힙니다.

개인정보 처리방침

최종 수정일: 2025년 10월 25일

1. 개인정보의 수집 및 이용

1.1 수집하는 개인정보 항목

  • 필수: 카카오 계정 ID, 닉네임, 프로필 이미지
  • 선택 (주자): 배번(bib), 준비 사진(레디샷)
  • 자동: 그룹 가입 일시, 역할(주자/응원)

1.2 수집 방법

  • 카카오 OAuth 2.0 인증
  • 사용자가 직접 입력하는 배번 및 사진
  • 서비스 이용 과정에서 자동 생성

2. 개인정보의 제3자 제공

RunCheer는 원칙적으로 사용자의 개인정보를 외부에 제공하지 않습니다.

예외: 사용자 동의 또는 법령 규정에 의한 경우

3. 개인정보의 처리 위탁

  • Kakao Corp.: 소셜 로그인 인증
  • Vercel Inc.: 서비스 호스팅 및 데이터 저장
  • Neon: 데이터베이스 관리
  • Vercel Blob Storage: 이미지 저장

4. 개인정보의 보유 및 이용 기간

  • 회원 정보: 회원 탈퇴 시까지
  • 그룹 정보: 그룹 삭제 또는 탈퇴 시까지
  • 이미지: 그룹 탈퇴 또는 회원 탈퇴 시 즉시 삭제
  • 탈퇴 회원: 즉시 삭제 (복구 불가)

5. 개인정보의 파기

5.1 파기 절차

  • 회원 탈퇴 시 데이터베이스에서 즉시 삭제 (CASCADE)
  • 그룹 탈퇴 시 멤버 정보 및 이미지 삭제
  • 그룹 삭제 시 모든 멤버 정보 일괄 삭제

5.2 파기 방법

  • 전자 파일: DELETE 쿼리로 완전 삭제
  • 이미지: Vercel Blob Storage에서 영구 삭제

6. 정보주체의 권리 및 행사방법

  • 조회: 앱 내 프로필에서 확인
  • 수정: 프로필에서 이름 수정
  • 그룹 탈퇴: "그룹 탈퇴" 버튼
  • 회원 탈퇴: "회원탈퇴" 버튼 (모든 정보 즉시 삭제)
⚠️ 회원 탈퇴 시 모든 개인정보가 즉시 삭제되며 복구할 수 없습니다.

7. 자동 수집 장치

  • localStorage: 그룹 코드 임시 저장
  • Kakao SDK: 로그인 상태 유지

8. 개인정보 보호책임자

성명: 성대경
직책: 개발자
연락처: GitHub Issues

9. 서비스 특성 안내

⚠️ 중요 안내
  • 베타 서비스로 예고 없이 중단/종료 가능
  • 그룹 코드를 아는 누구나 참여 가능
  • 실시간 추적은 공개 대회 데이터 기반 (GPS 수집 안 함)
  • 업로드 사진은 공개(public) 저장 (URL 공유 시 열람 가능)

10. 데이터 보안

  • HTTPS 암호화 (TLS/SSL)
  • SQL Injection 방지 (Prepared Statement)
  • Kakao OAuth 2.0 표준 준수
  • CASCADE 삭제로 관련 데이터 자동 삭제

이 개인정보 처리방침은 2025년 10월 25일부터 적용됩니다.
